# Kuymo integration

The public name, Dart package, Android namespace/application ID, iOS bundle IDs,
Kotlin source paths, native channels, plugin identifiers, notification channel
IDs, restoration bucket and compression workspace prefixes all use Kuymo.
Pigeon bindings are generated from the updated source configuration.

The Android/iOS application ID is `com.mostafa.sensei.kuymo` (with a test bundle
suffix for iOS tests). This installs as a separate app from differently
identified builds. Their preferences, history and jobs are not migrated.

GitHub release checks, sharing, support and source links point to the verified
`MostafaSensei106/Kuymo` repository. Obsolete artwork and exports were removed;
[the approved B kit](../kuymo/README.md) is the current source of brand assets.
