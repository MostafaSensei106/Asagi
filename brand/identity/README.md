# Asagi — current identity
Start with **brand-board.png**. The app icon and hero now use the same approved character.

- `masters/`: transparent raster and matching palette-vector artwork.
- `lockups/`: horizontal, stacked and dark combinations.
- `icons/app/`: 1024px opaque app tiles.
- `icons/web/`: favicon, sizes, manifest, safe-area icon.
- `mascot/`: separate Ready / Working / Done illustrations.
- `ui/`: supporting SVG controls.
- `GUIDELINES.md`: usage, typography, contrast and limitations.
- `presentation.html`: six relevant mockup contexts, generated with logo-design's presentation tool.
- `tests/`: size/reversal sheets and structural audit results.
- `process/`: prompts, brief and reproducible export scripts.

The detailed hero and optical favicon cut are related drawings. The vector palette rendering flattens shading, but does not replace the character with a different silhouette. Older rejected artwork lives outside this current kit.


## Additional mascot states
Six matching transparent 1024px illustrations added in `mascot/`: welcome, empty, analyzing, paused, error and share. Existing ready, working and done files remain unchanged. See `mascot/README.md`, `mascot/extra-states.json`, and `mascot/extra-states-overview.png`.
